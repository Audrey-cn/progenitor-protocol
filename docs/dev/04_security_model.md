# 安全模型

> 所属分类: concepts
> 生成时间: 2026-05-11

## Gatekeeper L0-L5 校验

| 层级 | 名称 | 内容 | 策略 |
|------|------|------|:--:|
| L0 | 速率限制 | PR ≤ 5基因, 人/天 ≤ 20基因 | 阻断 |
| L1 | 血脉校验 | life_id 以 PGN@ 开头 | 阻断 |
| L2 | 哈希校验 | 文件名 = SHA-256(内容) | 阻断 |
| L3 | 创造者契约 | 开放注册, 自动填充 Anonymous | 放行 |
| L4 | 质量门槛 | 元数据长度、文件大小、非空 | 警告 |
| L5 | 安全扫描 | 禁止 eval/exec/os.system 等 | 阻断 |

## Crucible 审计规则

- 环境变量注入检测 (`;` `|` `&` `` ` `` `$` 换行符)
- 危险指令检测（8类威胁）
- 空值拒止
- Agent 环境误报检测
