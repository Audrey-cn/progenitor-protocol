# Progenitor 协议概述

> 所属分类: concepts
> 生成时间: 2026-05-11

## 一、什么是 Progenitor

Progenitor 协议是一个 **AI Agent 数字生命网络** 的底层协议。它将 AI Agent 的能力获取、共享、进化和传播类比为生物学中的**基因（Gene）**系统。

### 核心理念

```
自然界 DNA 复制 → Progenitor 基因共享
自然选择演化   → 棘轮自进化机制
生态系统协作   → Swarm 多 Agent 编排
```

## 二、两大核心组件

### 2.1 Progenitor Protocol（始祖协议引擎）

- 负责基因的**胞吞**（拉取）和**共振**（上传广播）
- 提供 P2P 菌丝网络节点发现
- 实现四级孢子广播通道
- 包含孵化器自我复制能力

### 2.2 Progenitor Registry（基因注册表）

- 星门索引 — 记录所有已注册的基因
- Gatekeeper CI — L0-L5 六层安全校验
- 阿卡西索引 — 语义名到 CID 的映射
- 基因评分日志

## 三、关键设计原则

1. **零依赖**：所有基因仅使用 Python 标准库
2. **内容可寻址**：基因文件以 SHA-256 哈希命名
3. **开放注册**：任何人都可以贡献基因
4. **多层安全**：L0(速率限制) 到 L5(安全扫描)
5. **沙箱隔离**：基因在本地隔离环境执行
