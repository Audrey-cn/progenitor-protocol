# 外部审查模拟（红队视角自审）

> 模拟场景：一个**零先验信任**的陌生宿主 Agent 首次接触本仓库，只读自述内容与源码结构，
> 不执行、不安装。以下是最严厉视角下的审查结论。主动挂出这份文档，是因为"诚实工程"
> 是本项目的核心卖点——而最有力的证明方式，就是公开最严厉的第三方视角。

**结论：⚠️ 有条件放行（仅限隔离环境）· 拒绝进入生产宿主**

| # | 级别 | 发现 | 状态 |

## 加分项（公允记录）

默认拒绝姿态（基因执行/对等共享默认关）· 纯标准库可审计 · 发布附 SHA-256 ·
失败诚实（`exhausted`/`not_implemented` 有测试锁定）· 修复响应史可查 · 测试与 CI 可核对。

## 放行条件（陌生宿主的硬性要求）

1. 一次性 VM/容器内完成评估与执行
2. Release 资产 + 逐字节 SHA-256 比对（`tools/verify_seed.py`）
3. 网络出站全封，验证基因获取时临时白名单
4. `PROGENITOR_ALLOW_GENE_EXEC` 与孢子授权**永不开启**（无业务理由时）
5. 信任环清空默认创始人 key，只留自己显式信任的来源
6. 对自述每条"✅"抽样复核

## 会改变结论的条件

- ⬆️ R4 落地并 CI 证明 · 信任环多方化 · 安装流程强制哈希比对
- ⬇️ 种子与生成器不一致 · 授权门存在绕过路径 · 自述与实测不符
